# Changelog

## 1.0.0 — 2026-10-10

- First public release of the local Mihomo collector and dashboard.
- Daily domain, node, process and route aggregates with separate upload/download counters.
- Explicit unattributed traffic and coverage, bounded cardinality and 35-day daily retention.
- SQLite size limit, rotating logs, atomic checkpoints and restart handling.
- Date/path/group filters, CSV export and full-range ranking denominators.
- Protection against stale dashboard responses overwriting a newer filter selection.
- macOS user LaunchAgent installer, manager and data-preserving uninstaller.
- Custom Unix socket and dashboard port options.
- Sanitized background, accounting, operations and validation documentation.
